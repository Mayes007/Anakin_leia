# Skywalker Legacy: Anakin & Leia Media Hub

This project is a React-based web application that explores the parallel journeys of Anakin Skywalker and Princess Leia Organa. It features deep-dive character profiles, a thematic comparison of the Skywalker bloodline, a curated collection of iconic quotes, and an interactive "Neural Pattern" quiz to test user alignment with the characters' traits.

## Instructions for Build and Use

Steps to build and/or run the software:

1. **Clone the repository:** Use `git clone` followed by your project URL to download the files to your local machine.
2. **Install dependencies:** Open your terminal in the project folder and run `npm install` to download all necessary packages.
3. **Start the development server:** Run `npm start` to launch the local server and view the app in your browser.

Instructions for using the software:

1. **Navigate the Holocron:** Use the neon-bordered navigation buttons at the top (Anakin, Leia, Comparison, Quotes, Quiz) to switch between different content modules.
2. **Explore the Bloodline:** Read through the "Comparison" section to see the seven key parallels identified between Anakin and Leia’s leadership and emotional drives.
3. **Take the Neural Quiz:** Go to the "Quiz" tab and answer the 20 situational questions to see how your personality aligns with the Skywalker legacy.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* **Node.js:** Version 18.0 or higher for package management and runtime.
* **Vite / React:** Modern frontend tooling for component-based UI architecture.
* **Lucide-React:** (Optional) If used for the navigation and UI iconography.
* **CSS3:** Utilizing Flexbox, Grid, and Custom Properties for the "Force Neutral" gradient theme.
